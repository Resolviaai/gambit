# GAMBIT — Freelance Video Editor & Motion Designer Portfolio

A refined, high-craft, neo-brutalist portfolio for **Gambit**, built from scratch inspired by the visual design system and layout of [nuclearplayer.com](https://nuclearplayer.com/).

---

## 🎨 Visual Identity & Architecture

- **Website Name:** **Gambit**
- **YouTube Channel:** [youtube.com/@gambitone-m8d](https://youtube.com/@gambitone-m8d)
- **Direct Contacts:**
  - **Email:** `antetasks@gmail.com` (one-click copy with toast notification)
  - **Discord:** `gambit.one` (one-click copy with toast notification)
- **Typography:**
  - **Headings:** `Bricolage Grotesque` (Black, tight tracking, punchy uppercase)
  - **Telemetry & Timecodes:** `Space Mono` (Fixed-pitch, technical data format)
  - **Body Text:** `DM Sans` (Clean, editorial legibility)
- **Design System:** Neo-brutalist tactile cards, 1.5px solid borders, clean offset shadows (`3px 3px 0px var(--border)`), tactile button states, and zero AI slop.
- **Interactions & Motion:** Built with **GSAP 3.12+** and **ScrollTrigger**, featuring interactive Before/After color grade split slider, video player suite, and modal cinema playback.

## 🚀 Running the Portfolio Locally

From the `gambit` directory:
```bash
cd gambit
node server.js
```
Then open your browser at:
👉 **`http://localhost:3001`**

Alternatively, if running the root server from `c:\CODE\shoya`:
```bash
node server.js
```
Access at:
👉 **`http://localhost:3000/gambit/index.html`**
